Color reference
===============

All 256 color names accepted by the `colored <https://pypi.org/project/colored>`_
package -- usable anywhere this package takes a color, e.g. ``colcolor``,
``colbgcolor``, ``headcolor``, ``headbgcolor``, ``bordercolor``, and the
``fgcolor``/``bgcolor`` arguments of :meth:`~ansitable.ANSITable.row` and
:class:`~ansitable.Cell`.

This chart is generated at documentation-build time directly from the
installed ``colored`` package, so it always matches the version of
``colored`` actually in use. Type in the search box to filter by name, and
click a swatch to copy its name.
